# Submit your group's agent

1. [Fork the simulator](https://github.com/AhHamedi/somas-garden/fork) once per group and invite your teammates.
2. In your assigned folder (e.g. `teams/group-3/`), set your team name in `team.json`. Add either `agent.go` using the [Go starter](../public/society-example.go) or a visual behaviour in `builder.json`.
3. From the repo root, run `npm ci` and `npm run check:agents`. To play locally, run `npm run dev` and open the [group roster](http://127.0.0.1:8787/?groups).
4. Open a pull request to `AhHamedi/somas-garden:main` containing only your group's folder.
