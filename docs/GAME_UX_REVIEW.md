# Amoeboids: interface review

## Rebuild

The previous observer interface was rejected by the project owner on 15 November 2026: it stuttered, paused repeatedly, gave little sense of what was happening, presented plot data unclearly and did not show the rules or current votes. Earlier internal review scores for that interface are withdrawn and are not evidence of quality.

The interface was rebuilt from the engine's observer snapshots. The default respawn setting also changed: dead Amoeboids now return at the monthly meteor unless another delay is chosen in setup. The table records each complaint and the response.

| Complaint                                   | Response                                                                                                                                                                                                                                                                                                                  |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Lifeless world                              | Every Amoeboid is drawn and acts out its phase; lighting follows the day; weather, crops, halls, granaries and federations are visible.                                                                                                                                                                                   |
| Stuttering                                  | A single animation loop draws the map; phases arrive from a buffer stepped ahead of the screen; panels redraw only when their content changes; Amoeboids and crops are stamped from cached sprites.                                                                                                                       |
| Constant unpausing                          | Play never stops by itself. Selection, inspection, view changes and month ends leave it running.                                                                                                                                                                                                                          |
| No indication of what is happening          | The day console names the phase, shows its progress, tells the phase in one sentence with key figures, and notable events appear as notices. Plot overviews describe the current phase locally.                                                                                                                           |
| Unclear plot data                           | Four focused tabs: overview, residents, assembly and today. Numbers use one colour per resource.                                                                                                                                                                                                                          |
| Rules and votes not shown                   | The Assembly tab's statute book shows every possible law as a card, enacted or faded with its default, and selecting a card unfolds it in place with every option, parameter range and holder. Motions appear on plaques, in the plot's assembly tab and in the council chamber, with the passing line in the right unit. |
| Roles and influence not shown               | Crowns and pennants on the map, role badges and influence pips in tables, influence as size on the map, and a leadership section per plot.                                                                                                                                                                                |
| Too much text (second review)               | Explanatory paragraphs, captions and per-law descriptions removed; the assembly strip is three figures. Labels name things and the visuals carry the rest.                                                                                                                                                                |
| Inspector too small (second review)         | Widen button, double-click or drag to any width, remembered; the layout follows the panel's width and foldable sections stay folded.                                                                                                                                                                                      |
| Setup untidy (second review)                | Sectioned dialog with sliders and live charts for plot capacity, meals, field regrowth and weather; respawn defaults to the meteor.                                                                                                                                                                                       |
| Results too thin for a study (third review) | Engine-derived daily, per-vote and per-month records; outcomes, behaviour, commons and institutions with distributions, inequality, law adoption and voting by team; table views and CSV exports.                                                                                                                         |
| No reference for the laws (third review)    | A Rulebook view: every law, charter rule and decision with its options, ranges, voting rule, standing in each plot and history in the run.                                                                                                                                                                                |
